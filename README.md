# hESC Regression Effect Ranks

Interactive coefficient-rank ("volcano") viewer for the hESC CRISPRi high-MOI screen.
Each plot shows, for one gene, every guide's regression coefficient (x) against that
gene's rank within the guide's ~13k-gene coef profile (y; 0 = the guide's most
upregulated gene). DE and ES cell states; per state: genes with ≥15 FDR<0.05 guides
plus a curated set (~2k), plus 800 seeded-random background genes as negative
controls (tagged "random" in the picker). All ~13k guides always included; the
guide pool opens on active.

- `index.html` — the viewer (single file, no build step)
- `data/` — generated by the "Site Export" section of
  `hesc_highmoi_regression_and_analysis_iris_final.ipynb` (run on iris):
  `manifest.json` (per state: `genes`, `random` — the background sample, `files`,
  `featured`, counts), per-state `guides.csv` (guide,target,active), and
  `genes/<GENE>.csv` (coef,rank; rows align 1:1 with guides.csv, 3 sig digits)

Local preview: `python3 -m http.server 8000` then open http://localhost:8000/

To refresh data: re-run the export on iris, then
`scp iris:.../analysis_final/rankplot_site_data.tar.gz . && tar -xzf rankplot_site_data.tar.gz`
and commit.

## Publishing (not yet done)

One-time, from this directory, after `gh auth login`:

```bash
gh repo create hesc-regression-effect-ranks --public --source . --remote origin --push
gh api -X POST "repos/{owner}/hesc-regression-effect-ranks/pages" -f "source[branch]=main" -f "source[path]=/"
```

Site URL: `https://<github-username>.github.io/hesc-regression-effect-ranks/` (first deploy takes ~1 min).
Note: free-plan GitHub Pages requires the repo to be public — the site is
link-shareable but not access-controlled.

Later updates: commit changes, `git push` — Pages redeploys automatically.
